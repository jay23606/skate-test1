# skate-test1

A simple 3D skateboarding game built with [Three.js](https://threejs.org/). Ride down the course, dodge obstacles, jump ramps, and build your score.

## Play online

[Play skate-test1 on GitHub Pages](https://jay23606.github.io/skate-test1/)

## Controls

- **A / D** or **Left / Right Arrow**: Move
- **Space** or **Tap**: Jump / start the game
- **R**: Restart after a wipeout

## Run locally

Open `index.html` in a modern web browser, or serve the project with any static web server.
